# Richer 2D / cleaner UI — v2.5 (versionCode 34)

Biggest visual jump without changing engines. Chose 2D polish over Unity/Unreal.

## What shipped

1. **Cleaner UI chrome** — tighter main menu (section labels), settings (Coach / Audio / Run / About), inventory/shop/sheet/level-up panels; inventory action row scrolls on S20 so Sell/Transfer stay tappable.
2. **Battle presentation** — double-frame stage chrome, clearer HP/XP bars, brighter selected-target glow, stronger but readable hit/crit flash + floating damage (crit chip).
3. **Art refresh** — CC0 only: battlebacks re-encoded 960×540; new boss stage (`bg_battle_boss`); crisper party/enemy sprites with readability outline. APK art still modest.
4. **HUD** — production turn banner + XP bar + action row; tap-to-target, companion, audio toggles, sell/transfer preserved.

## Out of scope

Unity/Unreal, full 3D, rewriting game logic.
